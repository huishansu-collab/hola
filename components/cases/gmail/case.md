# 新用户查 Gmail 邮件

读取绑定记录，发现没有邮箱后搜索 Gmail 连接器。用户在助手说到“比如 Gmail”时插话“就 Gmail”，助手淡出停止，随后展示配置卡片并说明由用户确认绑定。工具与反应延迟为模拟设计值，录音按原速对齐。

| 时间 | 内容 |
| --- | --- |
| 0–3.65 秒 | 用户请求简述未读邮件 |
| 4.0–4.4 秒 | memory.get 返回无邮箱绑定 |
| 4.4–5.6 秒 | store.search 发现 Gmail |
| 6.0–11.32 秒 | 助手询问邮箱选择，说到“比如 Gmail”被打断 |
| 11.08–11.83 秒 | 用户：“就 Gmail。”，实际起声约 11.13 秒 |
| 11.2–11.6 秒 | audio.stop 工具窗口；11.2 秒下发，淡出 120 ms，11.32 秒停声 |
| 12.4–12.8 秒 | 展示 Gmail 配置卡片，返回 displayed |
| 13.2–18.432 秒 | 助手：“需要你自己确认绑定，Gmail 卡片发你了，按提示操作就行。” |

用户句子保持完整。被截断的“邮箱”不进入实播文本和合成音轨。停止播报不取消邮箱绑定引导。用户尚未点击卡片，用户控制轨道为空；尚无绑定成功或邮件读取结果。打断时间记录在 timeline.json，Annotation 不添加“打断”。


用户两句从同一次单人连续录音 user-master.wav 裁切；助手两句保持 session-master.wav 中已确认的录音。音色描述、原始录音、逐词转写和切点保存在 local/gmail。
