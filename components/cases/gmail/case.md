# 新用户查 Gmail 邮件

用户希望简述未读邮件中值得关注的信息。本案例展示新用户从无邮箱绑定到获得配置卡片的引导，工具和耗时均为模拟；语音未生成。

## 任务与依赖

1. 用户说完请求后，memory.get 读取 email_bindings，返回空列表。
2. 根据空结果调用 store.search，发现支持未读邮件读取的 Gmail 连接器。
3. 助手询问用户选择；用户确认配置 Gmail。
4. ui.show_connector_config 展示 Gmail 配置卡片，收到 displayed 后告知用户操作方法。
5. 等待用户完成配置，保留原始的邮件摘要目标。

## 时序

| 时间 | 内容 |
| --- | --- |
| 0–6.4 秒 | 用户提出未读邮件摘要需求 |
| 6.4–6.8 秒 | 读取邮箱绑定，结果为空 |
| 6.8–8.0 秒 | 搜索邮件连接能力，发现 Gmail |
| 8.4–15.6 秒 | 询问用户想绑定哪个邮箱，举例 Gmail |
| 16.0–18.4 秒 | 用户确认配置 Gmail |
| 18.8–19.2 秒 | 展示 Gmail 配置卡片 |
| 19.6–32.0 秒 | 告知卡片已展示，说明配置完成后可查看未读邮件 |
| 32.0–32.4 秒 | 等待用户配置 |

## 核对

- 本路径没有语音打断、战术垫句或等待音效。
- 卡片由助手展示，归工具调用。用户尚未点击，用户控制轨道为空。
- 未发生绑定成功回传，不调用 Gmail 读取邮件，也不编造摘要。
- 若卡片展示失败，应说明失败并允许重试；若用户改变邮箱选择，应重新核对可用连接器。
- case.json 和 timeline.json 保留完整台词、工具请求与返回、估计时间；生成语音后再对齐实际边界。
