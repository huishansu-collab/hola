# I2 · 口述消息，说错的当场改，拟稿只留对的

考口述改口的消化、微调措辞、改稿视为确认；发消息耗时为示意。

来源：《语音双工 - Explicit case》I2。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 37,600 ms，用户 3 段、
助手 3 段，工具调用 3 次。

## 台词与时序

| 时间（ms） | 用户音频轨道 | Assistant 音频轨道（实际播出） | 后台判断与反应 | AI 工具调用轨道 | AI 回复内容／表达控制 |
|---|---|---|---|---|---|
| 0–400 | 行为：（触碰LIVINGEDGE）→手机亮光 | — | 触碰唤醒，进入聆听态 | — | 暂不发声 |

| 12,000–16,000 | — | "拟好了，消息在屏幕上，发送么？" | 念稿等确认，不直接发送 | im.draft(周建军)即时完成 | 念稿确认 |
