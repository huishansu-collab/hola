# A1 · 出门前问要不要带伞

按400ms微轮次对齐，连续状态合并展示；考首音400ms内接话、结论先行、用户收尾后不追加废话；时间与工具耗时均为示意。

来源：《语音双工 - Explicit case》A1。语音已生成，下表时间按真实录音重排（台词依次落位，其余轨道按分段线性映射跟随）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 18,000 ms，用户 3 段、
助手 2 段，工具调用 2 次。
