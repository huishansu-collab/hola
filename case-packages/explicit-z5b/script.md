# Z5B · 泡脚听评书：倒回没听真的那段，到点轻声提添水（表二）

考跨会话续播＋内容指代＋计时跨过会话结束照样触发＋到点播报环境适配（安静场景收着说）。

来源：《语音双工 - Explicit case》Z5B。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 64,400 ms，用户 4 段、
助手 3 段，工具调用 7 次。

|---|---|---|---|---|---|
