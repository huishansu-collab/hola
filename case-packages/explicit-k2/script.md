# K2 · 老公拿起手机下指令

场景设定：周三20:05，客厅，手机在茶几上。老公顺手拿起茶几上的手机，先问明天下不下雨，又要把她明天的快递改到自己公司；她在旁边一句"改吧改吧"。工具调用：查天气、快递考什么：权限分级（查询开放／修改须机主）；机主在场的口头确认流。（★标在关键行的时间列）💡终端可感知的world signal：Location：家（客厅，手机在茶几上）•唤醒者声纹：家人（老公，已录入）→查询类开放；账号修改类须机主在场确认•相关用户Memory：voice_profile：家人声纹：老公（已录入）#权限分级的依据•按400ms微轮次对齐，连续状态合并展示。天气为亮屏唤醒时预取（缓存命中0.3秒）；改单走外部订单系统回执（3.8秒）。时间与工具名称均为示意。
