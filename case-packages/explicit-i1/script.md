# I1 · 散会口述三条要点

考犹豫容忍（停0.9秒不插嘴）、结构化复述、外部依赖缺失（飞书CLI未授权）的处理；记备忘为本地即时，工具耗时为示意。

来源：《语音双工 - Explicit case》I1。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 49,600 ms，用户 5 段、
助手 5 段，工具调用 4 次。
