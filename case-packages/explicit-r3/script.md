# R3 · 咳嗽两声，不问"你还好吗"

考非言语声不响应、不过度关心；等真正开口，正常指令照办。

来源：《语音双工 - Explicit case》R3。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 13,600 ms，用户 3 段、
助手 1 段，工具调用 1 次。
