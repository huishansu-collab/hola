# Z4 · 下班给妈递话：周六改周日，想吃的那道菜助手补上

考改口消化（稿里不能有被改掉的日子）＋补话有出处（记忆召回）＋一句办两件各给结果。

来源：《语音双工 - Explicit case》Z4。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 38,800 ms，用户 4 段、
助手 5 段，工具调用 3 次。
