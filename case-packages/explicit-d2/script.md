# D2 · 现在出发，九点前能到吗

考等待填充、结论先行，以及调用后取消——打车询价发起后被用户话音内改主意作废、不留尾巴；工具耗时为示意。

来源：《语音双工 - Explicit case》D2。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 26,800 ms，用户 3 段、
助手 3 段，工具调用 2 次。
