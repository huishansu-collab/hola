# E1 · 干着家务换歌调音量

考连发短指令的即时执行零废话、省略语（"再小点"）承接同一对象、用户说"行了"即收；工具耗时为示意。

来源：《语音双工 - Explicit case》E1。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 11,600 ms，用户 4 段、
助手 0 段，工具调用 3 次。
