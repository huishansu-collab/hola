# N1 · 吐槽开会，助手句间附和

考助手在用户吐槽会议时的句间附和与共情，以及顺手接一个重型文档编辑；文中工具耗时为示意。道（实际播出）具调用

来源：《语音双工 - Explicit case》N1。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 136,400 ms，用户 3 段、
助手 4 段，工具调用 1 次。
