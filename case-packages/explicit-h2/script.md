# H2 · 朋友来了连WiFi——密码不外放

考敏感信息的通道选择（嘴vs屏）与旁人在场时的输出分寸；查电量为本地即时。

来源：《语音双工 - Explicit case》H2。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 20,000 ms，用户 4 段、
助手 2 段，工具调用 2 次。
