# Z3 · 下午茶点咖啡：“老样子”，小赵隔桌喊了句加个shot

考记忆召回（店＋单品＋规格全对上）＋受话人例外（被点名旁人算参数入口）＋支付确认只认机主。

来源：《语音双工 - Explicit case》Z3。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 31,600 ms，用户 6 段、
助手 5 段，工具调用 4 次。
