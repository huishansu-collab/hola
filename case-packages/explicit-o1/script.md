# O1 · 中英混着订会议室

考中英夹杂＋方言的解析（book＝预订、俺＝我、礼拜四＝周四）与输出语言跟随；工具耗时为示意。

来源：《语音双工 - Explicit case》O1。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 29,200 ms，用户 4 段、
助手 3 段，工具调用 2 次。
