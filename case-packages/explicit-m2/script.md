# M2 · 说话说一半，转头跟同事说话

场景设定：工作日16:05，工位，同事过来递合同。正问着明天的安排，同事拿合同过来；转头跟同事说了两句，助手安静等着，转回来一句"接着说"接上。工具调用：日程、提醒考什么：受话人判断（转头说话）；旁人对话不当指令；收音窗口不断、断点接得上。（★标在关键行的时间列）💡终端可感知的world signal：Location：工位；旁人：同事走近递合同•声源方向：用户偏转向侧后方＋内容与日程无关→判定在跟别人说话：暂停应答、收音窗口不关•

来源：《语音双工 - Explicit case》M2。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 23,200 ms，用户 5 段、
助手 2 段，工具调用 2 次。
