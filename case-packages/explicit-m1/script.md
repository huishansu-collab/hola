# M1 · 帮把话说完（补话）

场景设定：周三15:20，工位，对着屏幕上的方案。对着方案理思路，说到"因为我们还没有——"把话头抛了出来；助手补了半句，补对了，顺手把两条风险记进了文档。工具调用：文档考什么：补话的判定与分寸；与I1"卡壳不抢话"是一对——那条不接，这条要接。（★标在关键行的时间列）音频轨道（实际播出）应用

来源：《语音双工 - Explicit case》M1。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 27,600 ms，用户 4 段、
助手 3 段，工具调用 3 次。
