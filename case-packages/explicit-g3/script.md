# G3 · 炒着菜定计时，顺嘴问生抽拿啥代

考噪音环境识别、多任务并行、生活问题短而能落地、到点播报在噪音下提音量；计时为本地即时，工具耗时为示意。

来源：《语音双工 - Explicit case》G3。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 532,800 ms，用户 4 段、
助手 2 段，工具调用 2 次。
