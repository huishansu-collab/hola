# B2 · 到家提醒收衣服，顺手加个兜底条件

按400ms微轮次对齐，连续状态合并展示；考必要复述与多余复述的分寸、两条件合并成一条、单次提醒不写长期记忆；时间与工具耗时均为示意。

来源：《语音双工 - Explicit case》B2。语音已生成，下表时间按真实录音重排（台词依次落位，其余轨道按分段线性映射跟随）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 21,600 ms，用户 3 段、
助手 4 段，工具调用 4 次。
