# D1 · 导航中：前面堵了，换条路

考路况查询的等待填充、只给一个方案就说清楚、收音关闭后导航照常播报；工具耗时为示意。

来源：《语音双工 - Explicit case》D1。语音已生成，下表时间按真实录音重排（台词依次落位，其余轨道按分段线性映射跟随）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 16,000 ms，用户 2 段、
助手 2 段，工具调用 2 次。
