# N2 · 说错日子当场自改，不硬拗

考助手自身口误的当场自改（周四→周三）与改口分寸——一带而过、不停下来解释；提醒创建为即时，工具耗时为示意。

来源：《语音双工 - Explicit case》N2。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 14,000 ms，用户 3 段、
助手 2 段，工具调用 2 次。

## 台词与时序

|---|---|---|---|---|---|
| 0–400 | 行为：（放下包按下LIVINGEDGE）→手机亮光 | — | 触碰唤醒，进入聆听态 | — | 暂不发声 |
