# J4 · 烟感报警，助手主动开口

场景设定：周日09:12，用户在阳台晾衣服，厨房烧着锅。人在阳台晾衣服，厨房的锅干烧冒烟，烟感把助手叫起来最大音量喊人；处理完让把油烟机开到最大。工具调用：播报、家居考什么：主动开口的门槛（P0立刻说）；喊一声就够；后续指令正常接。（★标在关键行的时间列）💡终端可感知的world signal：时间：UTC+8周日09:12•设备事件：厨房烟感触发（浓度持续上升，智能家居联动）→不等唤醒，wake_source=device_event•Location：用户在阳台（离厨房隔着屋）→音量拉满喊一声，有人应就闭嘴•音频轨道（实际播出）应用轨道0——烟感浓度持续上升，设备事件唤起（wake_source=device_event）；音量→max；灯环转红闪，全屏红色警示；随播报开启收音—先唤起，不铺垫
