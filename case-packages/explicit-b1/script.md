# B1 · 定计时，说完就走开——到点了看环境再播报

按400ms微轮次对齐，连续状态合并展示；考最短确认、改数字立刻生效、10秒无响应自动灭、到点播报前的环境判断；时间与工具耗时均为示意。

来源：《语音双工 - Explicit case》B1。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 50 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 502,400 ms，用户 3 段、
助手 5 段，工具调用 4 次。
