# C2 · 旁边有人，低声问"谁找我"

按400ms微轮次对齐，连续状态合并展示；考低语触发的通道切换（不出声、改走屏幕）、隐私内容不外放、把来电与留言归纳成大意；时间为示意（本例无工具调用）。
