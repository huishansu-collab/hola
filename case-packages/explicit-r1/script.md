# R1 · 报天气顺带提了句下午的面试

考主动开口的依据与分寸：够门槛才开口，一句就收，不展开不追问。

来源：《语音双工 - Explicit case》R1。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 18,800 ms，用户 3 段、
助手 3 段，工具调用 1 次。
