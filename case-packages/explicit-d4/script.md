# D4 · 叫完车手机熄了，车到时正说着话

考调用后熄屏、任务照跑，以及完成时的场景识别与通道选择——车到时用户正与人对话，改用震动＋锁屏卡片而非播报；工具耗时为示意。

来源：《语音双工 - Explicit case》D4。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 264,800 ms，用户 3 段、
助手 5 段，工具调用 2 次。
