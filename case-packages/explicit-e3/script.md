# E3 · 放着歌，孩子在旁边喊妈妈

考声纹区分——旁边孩子喊妈妈不当指令、只执行机主的话；工具耗时为示意。

来源：《语音双工 - Explicit case》E3。语音尚未生成，时间为文档示意值，
按 400 ms 微轮次吸附（原表整体偏移 0 ms，已减去）；工具参数与返回按原文保留成文本，
未虚构 API 字段。总时长 16,800 ms，用户 4 段、
助手 0 段，工具调用 2 次。
