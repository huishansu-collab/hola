# C3 · 发消息给张伟——通讯录里有俩

按400ms微轮次对齐，连续状态合并展示；考同名歧义一次问清（不按"最近联系"猜）、改稿即视为确认、结束用静默超时兜底；时间与工具耗时均为示意。

来源：《语音双工 - Explicit case》C3。语音尚未生成，时间为文档示意值，按 400 ms 微轮次吸附（原表整体偏移 50 ms，已减去）；
工具参数与返回按原文保留成文本，未虚构 API 字段。总时长 29,600 ms，用户 4 段、
助手 5 段，工具调用 2 次。
