# 验收与增量恢复

校验结构、交互与音频三个层面。报告已做的检查，保留未完成项；模拟时序、生成后对齐时序和生产日志实测分开。

## 自动检查

在项目根目录使用当前仓库的 `npm run case:validate -- <源包目录>` 和 `npm run case:build -- <源包目录>`。阶段未生成音频时，不宣称完整包通过；先核对脚本及结构，待音频到齐执行完整校验。

核对：UUID 身份稳定；manifest 与数据 ID/标题一致；毫秒范围；固定七轨；工具定义与实际调用、参数、返回配对及依赖一致；引用源音频存在且切点有效；回应间隔；打断各边界顺序；真实语音重叠；Annotation 对应表达；audio.play/audio.stop 及助手间隔；总时长与最终音频一致。

## 工具时间与业务边界

- 对照 interaction.md 的任务类别核对预算，区分模拟时序和实测延迟；新卡片格式化至显示约至少 1 秒，不能瞬时出现。
- 参数整理、网络执行、结果阅读与卡片展示各阶段不漏计、不重复累计；有依赖的动作等前置结果，用户补充信息或支付时间另计。
- 工具实际返回保留原时刻，下一次助手决策按 400 ms 网格；不能为了可视块宽度改写实际耗时。
- 按实际信息依赖检查语音与工具的重叠：已有结果的回答可与卡片渲染并行，不强制串行；未知结果不得提前播报，指向屏幕内容的台词须等对应内容可见。逐片段核对依赖时刻，不以整段语音或工具轨道是否重叠作为错误判据。
- 普通异步业务止于受理或派单；外卖／购物按 payment.md 例外覆盖支付及订单状态查询。凭证与返回状态一致，不包含车辆到达、配送或酒店后续确认等履约阶段，不安排分钟级履约等待。超时或失败不伪造成功。

## 等待策略、世界信号与表达控制

- 检查从用户请求结束到实质性回答的整条工具依赖链，计入串行步骤、后台判断和400 ms窗口，按实际阻塞路径计算，不重复累计并行耗时；工具切换不重置等待。
- 普通语音场景整体等待约2秒以上，应有简短垫句，适合时局部慢说；检查是否因“每个工具很短”或“会议场景”错误留下长时间未承接的沉默。明确静默、纯文字模式及支付操作等待按对应规则处理。
- 垫话与无需依赖结果的工具并行，不拖延执行，不提前宣称结果；不以刻意拖音或反复垫话填满等待。
- 每次改动工具依赖、400 ms时序或完成实际音频对齐后，重新计算等待及最长未承接沉默区间，再检查表达策略；不能只验证时间网格。
- 垫句、慢说分别关联助手实播片段；expression 和对应 fdx 标注不得关联用户或把纯文字标成语音慢说。
- 每个 audio.stop 都能追溯到同一 Case 中更早已启动的 audio.play，实例一致且工具轨道先 play 后 stop；拒绝孤立 stop 或引用 Case 外未记录的播放。
- Loading 有真实资产、播放/停止请求返回、实例关联及实际时段；任务提前完成或失败及时停止，与助手前后语音至少隔 400 ms，用户发言压低音量，明确停止则停止。
- Living Edge 双击记录为世界事件；悄悄话模式没有新增 TTS 或等待音效。进入时的在途声音有真实停止边界；之后助手轨道保留文字内容，没有伪造语音、波形或用户语音打断。
- 文字模式按实际契约检查渲染和导入导出；未经适配不可宣称已支持。退出需明确事件，不默认双击切换退出。

## 语义与听感

- 每个决策使用当时可见的信息，工具返回重新核对最新意图。
- 回答补足当前信息缺口；重复用户已给前提的句子应有纠错或消歧理由。
- 先判断查询必要性：模型已有知识可可靠解决的查字、释义、拼写、造句等直接回答，不存在虚构dictionary.search或为填轨道加入的占位调用。未用工具时工具轨道为空。
- 文字学习场景按[专用卡片规则](interaction.md#文字学习场景的专用卡片)检查识字、拼写、例句或近义词内容及 `ui.show_card` 请求/返回、轨道关联；只有用户明确无需卡片或设备无屏幕等已记录限制才省略。不得因无需查询而移除卡片；同一学习对象优先更新原卡片，打断后的更新跟随最新问题。
- 仅对实际需要外部查询的Case检查查询请求/返回及依赖；展示卡片独立判断，不强制前置查询。外部结果卡的字段对应真实或明确模拟的查询返回；直接回答卡片不得伪造source_event_id。
- 确实调用工具时检查完整事件和时间窗口；模拟展示事件与实际界面渲染的验收结论分开记录。
- 在途修改不提前成功、不重复创建，不播报失效旧结果。
- 用户控制为站内实际动作；口头确认、跳转、支付成功分开。
- 连续用户句未被拆开，未播出部分不进入历史轮。
- 使用 voice.md 的片段抽听清单，核对同角色音色、聊天自然度、鼻音、英文词、尾音和环境声。
- ASR 与样本波形均不能替代听感验收。无法试听时提供音频供用户确认。

## 平台检查

导入后检查七轨顺序、空轨默认折叠、音频与波形、播放定位、工具块及 JSON 详情。下载 ZIP 后在隔离测试目录/浏览器导入，检查同 ID 更新、刷新保留及音频引用。用户和助手最终 WAV 的物理左右声道需要检查实际样本，不能仅凭 Meta 标记判断。

只运行与改动相关的验证。纯标题和样式不重生成音频；修改台词后重新对齐关联时间，修改工具后重查 JSON 和依赖，修改音频后更新合成缓存。

## 失败恢复

记录已确认内容、成功产物、失败环节与下一步到源包说明。认证/额度失败不重试；已成功生成的响应优先恢复；漏词或音色失败诊断后最多自动追加一次完整母带生成。仍失败保留原版并报告具体缺陷。已有生成授权不扩展为未来无限请求。

导入失败保持当前版本；ZIP 缺少源文件时说明缺失，不能补造母带或生成记录。源码与工具适配器确实不支持当前资产类型时，完成适配和验证或明确报告阻塞，不用删除功能换取校验通过。

## 外卖与购物支付流程

- 支付卡片包含当前商品、金额、地址及可用配送信息；用户点击支付前已显示，要求点击卡片的台词前已可见。
- 发卡为工具调用，点击为用户控制，支付回调为世界信号；后台判断不可代替支付平台回调。
- 支付等待可留白，不编造成功或占位事件；取消／失败保留原状态。
- 支付成功回调与查询使用同一订单号，订单查询在成功回调后开始；商家接单或订单确认有对应结果支持。
- 待接单不得播报已接单；配送预计时间是结果字段，不变成分钟级 Case 等待。卡片更新与回答允许按依赖并行。

## 跨轨道依赖和显示验收

- 列出全部真实依赖边，逐条断言后续开始≥前置结束+400 ms；不是只比较起点。判断片段自身的400 ms时长不能抵扣间隔。覆盖世界回调→判断→工具、用户输入→判断、结果→播报等关系，不只修某张截图。
- 所有非人工片段起点均为400 ms整数倍；人工语音和点击保留实际时间。原始日志与模拟排程分别标明。
- 支付卡片已显示，至少400 ms后助手播报点击引导，播报结束至少400 ms后才有点击。校验音频中确实包含指引，不以卡片文字代替。
- 所有有参工具标题包含表意英文snake_case变量，无类型缩写、无字面量对象或数组；无参工具例外。变量绑定与实际query一致。
- 记忆查询明确读取内容；地点匹配在地址记忆和定位返回之后，数组等于上游结果，且满足跨轨道窗口。
- 实际导入最终ZIP检查标题、完整参数详情、全局世界金色及七轨区分。仅通过JSON校验不能宣称界面通过；没有浏览器验收能力时明确保留未验收项。
- 改工具显示、命名和时序复用母带；改台词重生成受影响角色完整母带。全部变化重新构建并校验ZIP及实际音频关联。

## 下单能力发现与准备验收

- 意图明确区分通用任务、品牌和具体商品；分类不改变用户明确商品。
- 检查位置、相关偏好和执行能力是否齐备；独立准备可并行，已知有效信息记录复用来源。缺失偏好不编造，当前要求优先。
- 查找MCP能力使用mcps.search；检查候选服务、支持范围和已知连接授权状态。不可直接跳到未发现、未确认可用的品牌业务工具。
- 保存发现、选择、业务执行的依赖与服务标识；发现结果返回后才判断选择，各跨轨道依赖保留至少400 ms。发现不等于授权或下单。
- 地点匹配使用已返回的当前位置和常用地址数组；下单工具参数、显示变量和所选服务对应。
