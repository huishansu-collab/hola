# TTS 执行与实际音频对齐

## 准备

先完成 SKILL.md 中的开场信息收集：用户角色性别、年龄及 TTS 凭据配置。默认模型为 `seed-audio-1.0`。先读取 voice.md，检查当前脚本确认和音频生成授权。用户已指定服务时沿用；检查项目配置和可用执行工具。使用已认可音色的 Prompt 与参数作为基线，记录 request 与母带的对应关系。

语音服务参数可能变化，首次在新环境接入或返回契约变化时查官方说明。当前 Seed 参考接口为 POST `https://openspeech.bytedance.com/api/v3/tts/create`，官方说明：`https://docs.volcengine.com/docs/6561/2550782?lang=zh`。参考请求使用 model=`seed-audio-1.0`、text_prompt、audio_config={format:mp3,sample_rate:48000,pitch_rate:0,speech_rate:0,loudness_rate:0} 和 watermark={}。参数值不能替代试听确认。

稳定音色说明只写一次。接着写当前场景和角色，再按顺序列完整台词，只有必要片段追加“持续鼻音”“略慢说”等一条局部要求。Prompt 过长可能降低台词覆盖，不重复粘贴所有验收条款。

用户与助手默认整段生成后裁切。同一角色每次重生成其完整台词母带；不把单独生成的短句混进旧角色母带。允许保留已满意的另一角色。严格角色环境声隔离时分角色生成整段，避免混合母带的环境声串入助手。

## API Key 配置

已有 `SEED_AUTH_FILE` 或用户指定的私有认证文件时，仅检查路径及可用性，不输出文件内容、不重复索要 Key。未配置时请用户通过可用的安全输入界面或本地终端隐藏输入，并保存在仓库之外、权限为 0600 的私有文件。认证头格式为 `X-Api-Key: <用户的 Key>`，随后只将文件路径提供给执行脚本。

普通自由文本提问框不作为密码输入框。当前工具没有安全输入能力时，请用户在自己的本地环境完成配置并提供路径；不要声称已经打开了不存在的安全输入界面。用户主动提供明文 Key 时不回显、不复制到产物；按其配置授权安全保存后只引用私有路径。

## 执行

包内 scripts/generate.py 复用已验证的 Seed 请求入口：

```sh
python3 /path/to/interaction-case-pipeline/scripts/generate.py request.json "$SEED_AUTH_FILE" staged-master.mp3
```

SEED_AUTH_FILE 指向外部私有认证头文件。只传路径，不输出认证头。不要将认证、签名 URL 或含完整原始响应的文件放入仓库、Skill、请求说明或交付包。脚本将原响应留在输出旁用于私下恢复；在制作临时目录执行，验收后只归档请求正文、音频和必要元数据。

每次使用新的暂存输出。成功生成后的下载或解析失败先检查原响应；不能直接重新请求。认证、额度错误停止。单次请求脚本有超时，长任务在支持的工具中异步观察，不阻塞对话更新。

## 对齐

1. 解码到 48 kHz、16 bit PCM WAV；格式解码不改变语速。工具以环境实际安装为准，例如 macOS afconvert 或 ffmpeg。
2. 使用已有 ASR 获取逐词时间戳。转写与指定台词逐句核对，短鼻音、英文词和极短确认句另听；不能仅根据 ASR 文本判断漏词。
3. 根据波形和试听微调切点，保留正常尾音，去掉无关录音间隙；不能靠剪掉“嗯”前的吸气冒充符合生成要求的持续鼻音。
4. 记录 generation/alignment.json，切点全部指向本次母带。源包 CLI 从这些切点生成片段与真实波形。
5. 以实际片段时长安排 Case，重新检查工具与发声关系。助手决策起点按网格，末端保持实测；用户起声可独立于网格。
6. 打断的真实尾段应用淡出，丢弃部分保持不播出。不要给整个片段加渐变，也不要把待丢弃的正文计入实际历史轮。

speech_rate=0 和原速播放并不保证听感正常，仍须按 voice.md 验收。语速或拖音不理想时，调整生成指令后重生成；用户明确要求后期处理才使用变速。

归档：请求正文、模型参数、生成时间与服务请求标识（可得时）、源母带、切点、验收结论。不要编造不可得的 seed、voice ID、实测延迟或已完成的试听结论。
